# Spam Message Detection Using Machine Learning

## Project Overview
This project uses Machine Learning to classify SMS messages as Spam or Ham (Not Spam).

## Objective
The main objective of this project is to detect whether a given SMS message is spam or a legitimate message.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)

## Dataset
This project uses the SMS Spam Collection Dataset for training and testing the machine learning model.

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Text Processing
5. Model Training
6. Model Evaluation
7. Spam/Ham Prediction

## Files
- `Spam_Message_Detection_Using_Machine_Learning.ipynb` – Google Colab/Jupyter Notebook containing the complete project.
- `Spam_Message_Detection_Using_Machine_Learning.ipynb - Colab.pdf` – PDF version of the project.

## Conclusion
The project demonstrates how Machine Learning and NLP techniques can be used to identify spam messages effectively.
